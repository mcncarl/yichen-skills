# yichen-social-bookmarks-exporter

Deprecated compatibility entry. The maintained implementation has moved to [`yichen-bookmarks-export`](../yichen-bookmarks-export/README.md).

Existing files remain in this directory for history and backwards compatibility, but the compatibility `SKILL.md` does not execute them. New installations and calls should use `yichen-bookmarks-export`.

The X route in the maintained Skill still calls [afar1/fieldtheory-cli](https://github.com/afar1/fieldtheory-cli) as an optional external runtime. No Field Theory source or binary is bundled.
