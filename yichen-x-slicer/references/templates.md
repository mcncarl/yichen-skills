# 模板注册表

默认模板是 `sunset`（落日琥珀版）。只有用户明确指定风格时才覆盖默认值。

| 参数 | 中文名 | 视觉特征 |
|---|---|---|
| `sunset` | 落日琥珀版 | 金黄、琥珀橙、暖米白与深棕；默认 |
| `editorial` | 暖白编辑版 | 暖纸、墨蓝细线、克制留白 |
| `data` | 冷白数据版 | 冷白底、深蓝数字、清晰网格 |
| `fire` | 火橙冲击版 | 火橙满版、近黑粗线、强开场 |
| `yellow` | 黄靛展览版 | 明黄块面、靛蓝文字、展览感 |
| `mono` | 黑白台账版 | 象牙纸、黑墨、硬边框 |
| `night` | 黑粉夜刊版 | 近黑背景、热粉强调 |
| `ribbon` | 奶油彩带版 | 奶油纸、多色斜带、复古活力 |
| `cobalt` | 钴蓝方格版 | 方格纸、钴蓝线、证据索引感 |
| `news` | 红黑报纸版 | 米白新闻纸、红黑对比、粗边框 |
| `minimal` | 极简留白版 | 纯白、浅灰、最少装饰 |

`--template all` 一次生成全部 11 套，仅用于用户明确要求的横向比较；普通请求只生成一套。默认情况下，每套模板各生成一条 MP4，不得把不同模板混入同一条视频；只有显式传入 `--images-only` 才跳过视频。模板只改变视觉外壳，不改变原生视频页的源音频规则：有源音轨时按该页时间轴保留原声，无源音轨时对应区间静音，全片没有任何源音轨时不生成音频流。
