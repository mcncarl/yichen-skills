# 视频固定规则

默认生成图片组、图片 ZIP 和 MP4，不需要额外参数。只有用户明确要求仅图片时才传入 `--images-only` 并跳过视频。

## 固定节奏

使用唯一配置 `fixed-reading-v1`：

- 帧率：30fps。
- 正文页：`clamp(54, 70, round(21 + 0.157 × text.length))` 帧，即约 1.8–2.33 秒。这里的 `text.length` 必须是原始 JavaScript 字符串长度。
- 原贴自身图片页：40 帧，即约 1.333 秒。
- 原贴自身原生视频页：按本地 MP4 实际视频流时长完整播放，页帧数为 `ceil(实际视觉时长 × 30)`；恰好落在整数帧时按该整数取值，不得因浮点误差多补一帧，也不得截短、循环或只显示封面。
- 相邻页面转场：固定重叠 4 帧，即约 0.133 秒。
- 总帧数：所有页面帧数之和，减去 `转场数量 × 4`。

这套规则就是默认且唯一的视频时间规则。正文页和图片页不得按内容之外的因素自行改时；原生视频页只服从实际视觉时长。不要暴露自定义时长参数。

## 运动规则

- 正文页和图片页的阅读停留区必须完全静止。
- 只允许在四帧换页窗口使用左右滑动或淡化。
- 禁止持续抖动、缩放、推拉、平移、旋转、透视、裁切和补边动画。
- 不缩放或裁切已经通过视觉检查的 1080×1440 图片。
- 原生视频页在已经通过视觉检查的媒体容器内 `contain` 居中播放完整源画面；只允许源视频本身的运动，不给它增加抖动、推拉、平移、裁切或循环。

## 音频规则

- 禁止生成或加入 TTS、配音、BGM 或音乐。唯一允许进入成片的音频，是选中非 Quote 原生视频自身携带的有效源音轨。
- 原生视频有音轨时，在最终成片对应视频页的源画面播放区间保留该原声：源音频起点必须与源视频首帧在最终时间轴上的实际起点对齐，后续持续时间必须与该页源画面保持同步，不得移到正文页、图片页或其他视频页。
- 原生视频无音轨时，对应源画面区间保持静音。正文页、图片页以及不属于有声源视频页的其他时间区间同样保持静音，不得用合成声音或其他素材填补。
- 只要至少一个选中原生视频有有效源音轨，最终 MP4 就保留一条仅由这些源音频按页面顺序和时间轴位置组成的音频流；若所有选中原生视频都无音轨，最终 MP4 必须没有音频流，而不是加入一条空白静音轨。
- Quote 媒体及其音频始终忽略，不得进入音频时间轴。

## 多模板与验收

- 单模板生成一条 MP4。
- `--template all` 时按模板分别生成 11 条 MP4；禁止把 11 套样式串成一条混合视频。
- 在安全 MP4 档位中优先选择长边至少 1080 像素的最低档，避免对 1080×1440 成片没有可见收益的 4K 下载与解码；若没有满足画布的档位，才使用最高可用 MP4。档位选择只影响分辨率和本地负载，不得改变或截短视频时长。
- FFmpeg 只读取本轮输出目录内、已经通过 PNG QA 的编号 PNG，以及经逐跳域名、MIME、MP4 签名、ffprobe 与完整解码检查的本轮原生视频副本。
- 输出固定为 1080×1440、30fps、H.264、`yuv420p`。
- 禁用场景切换自动关键帧，并把关键帧间隔设为长于整片，避免阅读区中途出现编码清晰度跳变。
- 先编码为 `.partial.mp4`，通过 ffprobe 规格检查和全片解码后再改为正式文件名。
- 自动检查除转场和原生视频动态区外的全部相邻帧对，正文页与图片页阅读区最低 SSIM 必须不低于 `0.9999`；不能只根据滤镜字符串宣称“不抖”。
- 每个原生视频必须检查实际视觉时长、视频流尺寸与编码、源文件哈希、完整解码、嵌入帧对应关系和源音轨存在性；任何一项失败都不得退化为静态封面。
- 音频验收必须先逐个探测选中原生视频的源音轨，再核对最终音频流存在性与源音轨集合一致。对每个有声源视频，验证成片非转场区的完整原声内容、起点和持续时间与源画面同步；四帧转场另用独立重建的原声时间轴逐段比对。对每个无声源视频及所有静态页，按 48kHz 整数采样验证完整静音补集，不能只抽查几个窗口。
- AAC 边界容差只允许出现在每个原声起止边界相邻的 1024 个采样内，并必须通过独立预期时间轴比对；边界带之外的静音区峰值不得高于 -60dBFS、均值不得高于 -80dBFS。允许原声区、严格静音区和边界带的采样数之和必须严格等于整条时间轴。
- QA 与 manifest 记录每页帧数、转场数、总帧数、时长、来源 PNG 哈希、原生视频探测与嵌入证据、每个源视频的音轨存在性和音频时间轴区间、转场与静音补集覆盖、最终音频流存在性与对齐结果、MP4 哈希和逐帧静态阅读区验收结果；同时记录渲染脚本、主脚本、测试、`SKILL.md` 及 Node.js、FFmpeg、ffprobe 的运行时版本或哈希，以便成片与实际代码绑定。
